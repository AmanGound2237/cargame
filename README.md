# 🏎️ Cyber Velocity — Multiplayer Typing Car Race

A real-time multiplayer cyber racing game powered by typing speed and accuracy. Built with Node.js, Express, Socket.IO, Canvas 2D, and Web Audio API.

## 🚀 Features
- **Real-Time Multiplayer**: Join with 5-letter room codes or shareable invite links across cities and devices.
- **AI Bot Racers**: Quick Race solo against 3 AI competitors or add bots to fill empty slots.
- **Dynamic Speedometer & Transmission**: Gauges shift in real-time from Gear 1 up to Hyperdrive Nitro.
- **Supercar Visuals**: Neon underglow, projector headlights, and twin expanding nitro exhaust flame jets.
- **Zero-Dependency Sound**: Web Audio API sound synthesizer for engine revs, tactile clicks, and fanfares.

## 🛠️ Local Development
```bash
npm install
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
